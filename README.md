# Academy Arduino

Colección de proyectos educativos con Arduino UNO.

## Proyectos incluidos

- **blinkin_led** - Parpadeo de LED básico
- **pulsador_digital** - Lectura de pulsador digital
- **fotorresistencia** - Sensor de luz (fotorresistencia)
- **lcd** - Display LCD 16x2
- **lcd y ultrasonidos** - LCD con sensor ultrasónico HC-SR04
- **prueba_servo** - Control de servo motor

## Requisitos

- Arduino UNO
- VS Code
- PlatformIO IDE (extensión para VS Code)
- Arduino IDE o controladores USB para Arduino

## Instalación

1. Clona este repositorio
2. Abre la carpeta en VS Code
3. Instala la extensión PlatformIO
4. Selecciona el proyecto que desees trabajar
5. Compila con `Ctrl+Alt+B`
6. Sube el código con `Ctrl+Alt+U`

## Librerías utilizadas

- LiquidCrystal (para LCD)
- Stepper (para motor paso a paso)
- Servo (para servo motores)
